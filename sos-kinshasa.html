Comment ça fonctionne
1
Inscrivez-vous et obtenez votre code
Créez votre profil avec votre commune, vos contacts d'urgence. Vous recevez un code unique KIN-XXXX lié à votre identité et localisation.
2
Partagez votre code avec votre famille
Votre famille peut envoyer ce code au centre d'alerte si vous ne rentrez pas à l'heure prévue ou si vous avez disparu.
3
Déclenchez le SOS en cas de danger
Appuyez sur le bouton rouge, sélectionnez le type d'incident (Kuluna, Kidnapping, Intrusion...). Votre position GPS est envoyée automatiquement.
4
Le centre de crise intervient
Le centre reçoit l'alerte avec votre code, votre position, le type d'incident et vos contacts. Une équipe de réponse est déclenchée.

🇨🇩 À propos de SOS Kinshasa

Ce prototype a été conçu pour répondre aux défis sécuritaires de Kinshasa : kidnappings, phénomène Kuluna, intrusions domiciliaires et agressions armées. Pour un déploiement réel, ce système nécessite un partenariat avec la Police Nationale Congolaise, la Mairie de Kinshasa, et les opérateurs télécom (Airtel Congo, Orange RDC, Vodacom Congo) pour le système USSD et SMS court.
